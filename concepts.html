✅ Pros

  • Visually distinctive — no other mobile app has CRT scanlines
  • Phosphor glow on numbers makes data pop without chart elements
  • Scanlines & vignette are a single overlay View — minimal perf impact
  • Beveled borders add depth without rounding corners (keeps terminal soul)
  • Works with existing feed architecture — no layout changes needed

    • ⚠️ Cons

  • Scanlines reduce perceived brightness — may feel dim on actual phone
  • CRT aesthetic may feel dated/"retro" rather than premium
  • Phosphor glow text-shadow can cause rendering blur on thin fonts
  • Doesn't fix the existing spacing/sizing issues — pure overlay
  • Vignette darkens corners where action buttons might sit

    ✅ Pros

  • Creates strong visual hierarchy through colored ambient light — urgency is "felt" not just labeled
  • Semi-transparent cards reveal the glow underneath, creating depth
  • 8px rounded corners on cards makes them feel polished without iOS-level rounding
  • Color rail + glow + border = triple encoding of urgency (accessible)
  • No scaling or layout changes needed — works with existing card architecture

    • ⚠️ Cons

  • Blur effects can be expensive on older mobile GPUs
  • 8px rounded corners may feel off if you want strict terminal purity
  • Glows overlapping could look muddy if cards are close together
  • Semi-transparent cards reduce contrast for the text inside
  • Radial gradient glow may not map cleanly to React Native (SVG filter?)

    ✅ Pros

  • Content-adaptive height: cards are tall when there's data, short when there isn't — kills wasted space
  • 8px rounded corners + colored shadow = polished but not iOS; keeps terminal DNA
  • Phosphor text treatment makes numbers pop — gives data visual weight without charts
  • HUD bar adds live status feel without touching card architecture
  • Hybrid fonts (sans-serif for narrative, monospace for data) improve readability
  • Animations (pulse dot, live indicator) feel alive but minimal

    • ⚠️ Cons

  • Biggest layout refactor: cards need to support variable height
  • Box shadows in React Native can be limited (no multi-shadow in older versions)
  • Sans-serif body text abandons pure terminal look — may not feel "terminal" enough
  • HUD bar takes vertical space on an already-tight mobile screen
  • Phosphor glow text-shadow may not render identically across devices
