⡂ Dark Web Detail — Design Decisions

Header section: Token avatar with urgency-colored border. Title and summary in sans-serif for readability. Key observations use green phosphor numbers for positive signals.

Metadata bar: Sentiment badge (+colored border), confidence score, category tag, scan ID. All in pill-style chips with subtle borders.

Analysis blocks: Same block components as feed, but full-width and detail page. Metrics display as side-by-side cards. Charts show full bar charts with rounded bars and opacity gradients. Tags appear here (never on feed).

Market data table: Clean monospace rows with phosphor-styled values. Sources as clickable cards with domain metadata.

Consistent Dark Web patterns: 8px radius throughout, colored shadows on urgency elements, hybrid fonts (sans-serif for narrative, monospace for data), phosphor glow on all numeric values, live pulse dot in top bar.
