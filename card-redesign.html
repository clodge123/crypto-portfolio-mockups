🆡 DESIGN PRINCIPLES
• Card = fixed 430w × 580h (taller Instagram-style rectangle)
• Blocks dynamically allocate card real estate based on count
• 2-3 blocks → each gets generous space (1/2 or 1/3 of card each)
• 4-7 blocks → medium sizing, compact layout with grid
• 8+ blocks → tight grid, mini-block mode, swipe/scroll inside
• Block types have minimum heights — some always get more room
• Content overflow → slides to detail page (not cut off)

◊ OPTION A: ADAPTIVE 2-COLUMN GRID

Blocks snap to a 2-column grid within the fixed card. Block sizes adjust based on how many blocks exist.
✓ Predictable layout · Always fills card evenly · No dead space
✗ Some blocks forced into half-width when they'd look better full · Grid math gets weird with odd counts

◊ CARD vs DETAIL: BLOCK ALLOCATION SYSTEM

✦ ALWAYS ON CARD (TIER 1)
These always render on the feed card. They're the core signal.
text (title) metric metrics_row tags text (subtitle) risk_meter sentiment
✦ FLEXIBLE (TIER 2)
Rendered on card if space allows. Moved to detail if too many blocks.
text (body/long) list progress divider
✦ DETAIL-ONLY (TIER 3)
Too large for the card. Always go to detail page where there's full vertical space.
chart donut whale_card image
🆡 ALLOCATION ALGORITHM
1. Start with card height = 580px (fixed)
2. Subtract header (token + urgency + timestamp) → ~60px
3. Available = 520px for blocks
4. Sort blocks by tier: T1 → T2 → T3 (T3 → detail immediately)
5. Calculate each block's natural height (based on content & type)
6. Sum T1 heights + T2 heights. If total ≤ 520px → all fit, scale evenly
7. If total > 520px → drop T2 blocks to detail, recalculate
8. If still > 520px → scale down proportionally with minimum sizes
9. If still > 520px after min sizes → card gets internal scroll, rest on detail

◊ LAYOUT MODES: How Block Count Shapes the Grid

# Blocks Mode Grid Block Height Notes
1-2 GENEROUS 1-col, full width ~175-260px each Each block gets tons of room. Charts/images look great here.
3-4 COMFORTABLE 1-col + 2-col splits ~130-170px each Sweet spot. Most cards will fall here. Metrics go 2-col, text goes 1-col.
5-6 COMPACT Mixed grid (1-col + 2-col) ~85-105px each Good density. Mini-metrics, short text, compact lists.
7-9 DENSE 2-col + 3-col splits ~55-75px each Data-dense mode. Mini everything. Some blocks overflow to detail.
10+ OVERFLOW T3 blocks → detail ~45-55px min LLM output too dense. Push non-critical blocks to detail, card shows headlines only.
