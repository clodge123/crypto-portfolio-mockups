⡂ Design System Breakdown

⡂ 1. Weighted Neon Top Bar
Currently all cards have a uniform 1px top border. In Term-Plus, the top bar's thickness scales with urgency:
INFO • 2px WATCH • 2px ALERT • 2.5px URGENT • 3px CRITICAL • 4px + outer glow (box-shadow)

This creates felt urgency — critical cards literally loom larger in the scroll without adding visual noise.
⡂ 2. Per-Block Accent Rails
Each block inside a card gets a 2px left-side vertical rail, color-coded by block type:
text → #6C3BFF (purple/analysis) metric → #00C96C (green/data) chart → #00BFFF (cyan/visualization) callout → #E0C000 (warning/signal) sentiment → #FF44AA (pink/AI) social → #FFB02D (orange/social)

This turns a flat wall of blocks into a visual rhythm — you can scan a card by the rainbow of left rails alone.
⡂ 3. Block Dividers (§)
Between logical block groups, a thin line + centered § dot in #6C3BFF. Groups are: header section, data section, analysis section, meta section.
This replaces the current "everything just touching everything" feel with intentional breathing room.
⡂ 4. Hybrid Font Stack
Currently 100% Courier New. In Term-Plus:
Card titles → system-ui (sans-serif)
Narrative text → system-ui (sans-serif)
Metrics, labels, timestamps, badges → Courier New (monospace)

This is the biggest readability win — prose is read in a proportional font, data stays in monospace where it belongs. Terminal feel preserved for everything data.
⡂ 5. Meta Bar (Provenance Line)
Every card gets a thin meta bar at the bottom showing:
● scan #284 · conf 0.84 · $4.2K liq · 2m ago · [DEEP]

Makes each card feel like an intelligence report with provenance. Also useful for debugging — you can see which scan generated it and how confident the model was.
⡂ 6. 🤖 AI Watermark
A subtle 🤖 v1.0 stamp in the bottom-right of every card in #FF44AA at 35% opacity. Brand recognition without being in-your-face. Like a terminal MOTD.
⡂ 7. Active Tab Underline (Tab Bar)
Active tab gets a 2px neon underline (like ▃▃▃) instead of just color change. Feed tab shows a blinking status dot when new items are streaming in.
⡂ 8. Card Entry Animation (Future)
New cards fade in with opacity: 0 → 1 + slight translateY: 20px → 0 as they enter the viewport. Like less in terminal. Subtle but makes the feed feel alive.

⡂ Recommended Build Order

Phase 1 · Data Layer (safe, no visual risk)
Add blocks[].type metadata to each block object in the backend feed response. No rendering changes yet.

Phase 2 · Accent Rails + Block Dividers
Update BlockFrame in CardRenderer.tsx to render the left rail and conditional dividers between blocks. This is the highest-impact visual change and can be done in one component.

Phase 3 · Weighted Neon Bar
Update the card's top border in index.js (feed) and TerminalCard.tsx (detail) to use thickness + glow based on urgency.

Phase 4 · Hybrid Typography
Switch card title and narrative block text to system-ui (sans-serif). Keep block-metric, labels, badges, meta in Courier New. Update font utilities in ThemeContext.

Phase 5 · Meta Bar
Add a new MetaBar.tsx component and inject it into the card footer in feed renderItem. Pull data from item.scanId, item.confidence, item.liquidity, item.scanType.

Phase 6 · AI Watermark
Add 🤖 v1.0 stamp to TerminalCard.tsx. One line.

Phase 7 · Tab Bar Enhancements
Add neon underline to active tab + blinking status dot on Feed tab when new items arrive.

⡂ TL;DR

Term-Plus is the same terminal feed you know — same black bg, same neon urgency, same 1-per-scroll cards — but with visual texture added through: accent rails, block dividers, weighted neon bars, hybrid fonts, meta bars, and AI branding.

Nothing changes about the feed layout, scrolling, or interaction model. It just looks more professional, more polished, and more like a finished product — without losing the terminal soul you chose.
