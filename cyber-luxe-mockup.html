⡂ Block Redesigns — Cyber-Luxe Upgrades

Every block type gets visual upgrades. Here's what changes and why.

Card Headers

Sparkline thumbnails + gradient neon top bars
▌ Before: Flat 2px color bar, text-only header
✓ After: Gradient neon bar (2-5px by urgency) + inline SVG sparkline

Metric Blocks

Biger numbers, colored trends, visual weight
▌ Before: 16px value, small trend icon
✓ After: 22-28px bold value, inline colored trend, optional mini sparkline

Metrics Row

Tiler columns with dividers
▌ Before: Blocks of text with flex spacing
✓ After: Vertical divider pipes, aligned values, subtle column bg

Callout Blocks

Neon glow effect + icon + semantic color
▌ Before: 1px border with label
✓ After: Border + glow, bolder icon, 3-line cap with fade

Chart Blocks

Tilinne price history with gradient fill
▌ Before: Simple SVG polyline, no fill
✓ After: Polyline + gradient area fill + axis labels

List / Timeline

Color-coded bullets, gutter rails
▌ Before: Plain text list, uniform color
✓ After: Color-coded bullets (red/yellow/cyan), left gutter rail

Sentiment

Gauge bars with proportional fill
▌ Before: Three numbers with labels
✓ After: Stacked gauge (green+gray+red), proportional widths

Transfer

Visual from→to arrow flow
▌ Before: Plain text "From X to Y"
✓ After: Left box → right box, colored amount badge, truncation

Progress / Risk

Segmented bars with danger zones
▌ Before: Simple single-value bar
✓ After: Multi-segment with color zones (safe→warning→danger)

Quote

Social embed with attribution
▌ Before: Plain text quote
✓ After: Left quote rail, italic text, "— author @source"

⡂ Visual Specifications

Design tokens for the Cyber-Luxe upgrade.

Typography

Card title: 15px bold · #E0E0EC
Metric value: 22-28px bold · urgency-colored
Block body: 10-11px · #A0A0AA
Labels/tertiary: 8-9px · #888
Meta footer: 7-8px · #666

Neon Glow (box-shadow)

critical: 0 0 12px(0.2) + 0 0 3px(0.4)
urgent: 0 0 8px(0.15) + 0 0 2px(0.3)
alert: 0 0 6px(0.12)
watch/info: no glow

Gradient Top Bars

critical: 5px · linear-gradient(to right, #FF0044, #FF3366)
urgent: 3px · linear-gradient(to right, #FF6633, #FF9944)
alert: 3px · linear-gradient(to right, #E0A000, #FFC000)
watch: 2px · linear-gradient(to right, #44BBAA, #66DDCC)
info: 2px · linear-gradient(to right, #3388CC, #55AAEE)

Card Anatomy

┌─ gradient neon top bar (2-5px) ───────────────┐
│ header: [icon] SYMBOL type sparkline │
│ Title: Bold, urgency-colored │
│ Summary: 2-3 lines, secondary color │
│ Tags: pill chips │
│ Block content (with accent rail) │
│ Block content │
│ Meta bar: ● confidence · scan · time │
└──────────────────────────────────────────└
height: 180-320px · padding: 14/16 · rails: 3px colored strip

Card Weight by Urgency

critical: thicker bar(5px) + glow + bolder text colors
urgent: medium bar(3px) + subtle glow
alert: medium bar(3px) + faint glow
watch: slim bar(2px) + no glow
info: slim bar(2px) + no glow
Weight scales together: bar + glow + color intensity

Press / Hover States

Press: card border brightens 20%
Active: glow intensifies slightly
Transition: 150ms ease
