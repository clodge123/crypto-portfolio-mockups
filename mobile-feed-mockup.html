Animation Style Reference

7 animation primitives. Each has a feeling, best blocks, and overuse caution.
1 blink Urgent · attention Max 1/card
2 breathe Gentle pulse · alive Safe default
3 pulse-bar Live progress Bars only
4 float Bobbing · subtle life Avatars only
5 glow Border pulse · urgent Max 1/card
6 slide-in Reveal · stagger On-mount only
7 color-shift Rainbow · dynamic Max 1/card
Rule: Max 2 animation types per card. breathe is the safe default — subtle enough for 3-4 instances. blink + glow + color-shift are high-impact — use sparingly (max 1 each per card).
